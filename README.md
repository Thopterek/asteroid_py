# asteroid_py


<img width="1238" alt="asteroid_game" src="https://github.com/user-attachments/assets/a8de0774-6d68-4757-8ddb-4c56642896f9" />
A simple 2D asteroid game built with Pygame where you control a spaceship to shoot and avoid asteroids.

## Features

- Player controls (rotate, move, shoot)
- Asteroid spawning with random sizes and velocities
- Collision detection between player, asteroids, and shots
- Asteroid splitting when hit by shots
- Screen edge wrapping for asteroids

## Requirements

- Python 3.x
- Pygame

### How to Run

1. Clone the repository:
```bash
git clone https://github.com/Thopterek/asteroid_py.git
```
2. Install Pygame (if not already installed):
  ```bash
  pip install pygame
  ```
3. Run the game
  ```bash
  cd src
  python main.py
  ```
#### Controls

- W/S: Move forward/backward
- A/D: Rotate left/right
- SPACE: Shoot
- Close window: Quit game

I hope to add more but for now just enjoy the game!
